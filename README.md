# 🍃 Food Waste Redistribution SQL Project

## 📌 Project Overview

The **Food Waste Redistribution SQL Project** focuses on managing and organizing surplus food information to support the redistribution of available food from providers to receivers.

The project uses SQL to work with food-related data, manage database records, and retrieve relevant information about food providers, receivers, food availability, and redistribution.

## 🎯 Project Objectives

- Manage food provider and receiver information.
- Maintain records of available surplus food.
- Retrieve food details using SQL queries.
- Understand the relationship between food providers and receivers.
- Support the organized redistribution of surplus food.
- Promote the effective use of available food resources.

## 🛠️ Technologies Used

- **SQL** – Database queries and data manipulation
- **Relational Database Concepts** – Tables, records, and relationships
